**Petunia 01.001.000: the first Petunia, based on ProsperoRadio 01.000.010.** Petunia is Oliv3rmoon's release of ProsperoRadio, created by **BlackBearReloaded** and continued by **bornaradusin**: ProsperoRadio 01.000.010 with a new name, Nightshade's look in chartreuse, and updates from this repository. A test release.

## What changed

- **Its own app.** Petunia is its own title, `PPSA99017`, with its data in `/data/petunia`, so it installs beside ProsperoRadio instead of over it. Favourites and settings are not shared.
- **The look.** Nightshade's black with chartreuse: near-black pages, black glass panels, a chartreuse accent for the main actions and the focus, and a near-black sky with a low olive glow. "On air" is the family's red.
- **The art.** A new icon, the petunia's trumpet as a speaker horn, and new home-screen and launch pictures.
- **Credits.** The About page and the About dialog name BlackBearReloaded, who created ProsperoRadio, and bornaradusin, who continues it, with Radio Browser, and nightly on Discord.
- **Updates from this repository.** Petunia asks [Oliv3rmoon/Petunia](https://github.com/Oliv3rmoon/Petunia/releases) for a newer full release and installs it with **Update now**, after checking `PPSA99017.zip` against `SHA256SUMS`. Test releases like this one are not offered.

Playback, the catalogue and the interface are ProsperoRadio 01.000.010's. Built and checked by the host tests in CI; not yet run on a console.

## Install

- `PPSA99017.zip`: extract it and upload the whole `PPSA99017` folder to `/data/homebrew/PPSA99017/`, then let ShadowMountPlus discover it.
- `SHA256SUMS`: the checksum of the download. `gh attestation verify PPSA99017.zip -R Oliv3rmoon/Petunia` checks that this repository's workflow built it.
